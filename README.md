# The $9 Billion Drop of Blood

A 19-page broadsheet web slideshow on the Theranos / Elizabeth Holmes fraud (2003 to 2026), built as one
self-contained HTML file per language, with self-hosted fonts (no CDN) and openly licensed photographs
from Wikimedia Commons, credited on the last page.

- English: https://nine-billion.surge.sh (mirror: this Pages site)
- Persian, right to left: https://nine-billion-fa.surge.sh (mirror: /fa/ here)

Keys: arrows, space, Home/End, O for contents, P for autoplay, F for fullscreen, ? for help.
In the Persian build the left arrow advances, since the deck reads right to left.
Click the outer thirds, swipe on a phone, or scroll. Print gives one page per sheet.

Every figure in the deck carries its source on the page where it appears. No reconstructed quotes,
no invented dialogue, no AI generated imagery.
